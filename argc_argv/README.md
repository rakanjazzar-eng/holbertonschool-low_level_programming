# C - argc, argv

## Description
This project covers the concept of command-line arguments in C programming, exploring how to use `argc` and `argv` to receive inputs directly from the terminal, handle unused parameters safely, and enforce proper program execution.

## Requirements
* **Allowed Editors:** `vi`, `vim`, `emacs`
* **Compiler:** `gcc` on Ubuntu 20.04 LTS using `-Wall -Werror -Wextra -pedantic -std=gnu89`
* **Code Style:** Betty style (`betty-style.pl` and `betty-doc.pl`)
* **Header File:** `main.h` with include guards.
* **Forbidden:** Global variables, more than 5 functions per file.
